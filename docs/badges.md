# Badge & Shield Reference

All badges use [Shields.io](https://shields.io) with a consistent `style=flat-square` (nav/contact badges) or `style=for-the-badge` (coding-profile cards), and the same dark `labelColor`/`bg_color` (`#0D1424`) so every badge matches the SVG panel color.

## Updating your username

Search-and-replace `Skc-VitInProjects` across:

- `sections/hero.md` (profile views, followers)
- `sections/stats.md` (all stats/graph/snake URLs)
- `sections/coding-profiles.md`
- `.github/workflows/*.yml`

## Third-party badge services in use

| Service | Used for | URL pattern |
|---|---|---|
| [readme-typing-svg](https://readme-typing-svg.demolab.com) | Animated typing headline | `?font=...&lines=...` |
| [komarev.com/ghpvc](https://komarev.com/ghpvc) | Profile view counter | `?username=...` |
| [github-readme-stats](https://github.com/anuraghazra/github-readme-stats) | Stats card, top languages | `?username=...&theme=...` |
| [github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats) | Commit streak | `?user=...` |
| [github-readme-activity-graph](https://github.com/Ashutosh00710/github-readme-activity-graph) | Contribution graph | `?username=...` |
| [platane/snk](https://github.com/Platane/snk) | Contribution snake animation | generated by `snake.yml` |
| [progress-bar.xyz](https://progress-bar.xyz) | Learning-progress bars | `/<percent>/?color=...` |

## Adding a new badge

Keep new badges on the same palette:

```md
![Label](https://img.shields.io/badge/LABEL-VALUE-COLORHEX?style=flat-square&logo=LOGO&logoColor=white&labelColor=0D1424)
```

Use `00E5FF`, `4C6FFF`, or `B24BF3` as the `COLORHEX` to stay on-brand.
